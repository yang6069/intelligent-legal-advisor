## 一、测试概述

### 1.1 测试目标

依据《智法通 · 企业级智能法律顾问平台项目需求文档》，对系统进行全面的功能测试、性能测试与用户体验测试，验证：

1. 全部功能模块（智能问答 / 合同审查 / 知识库 / MCP 工具 / 数据分析 / 审计日志 / RBAC 权限）实现完整且运行正确；
2. Docker 容器化部署后各服务健康、链路（前端 Nginx → 后端 FastAPI → MySQL/Redis/Neo4j/Ollama/Rerank）贯通；
3. 不同角色登录后展示与其权限匹配的菜单与界面；
4. 核心性能指标满足可用性要求。

### 8.3 法条共引关系网络数据来源（说明）

- **来源**：智能问答每次回答携带的法条引用记录（qa_messages.citations，由 RAG 检索真实命中产生）；
  统计任务对每条回答内的引用做两两组合（共引对），聚合 Top50 形成网络——节点是法条/知识库文档，边为共引次数；
- **编辑入口**：「知识库管理」页（法务负责人/管理员）增删改法条文档（法律名称/条文号/正文），
  新回答的引用即时纳入统计；仪表盘「图谱节点」KPI 则来自 Neo4j GraphRAG 图谱（知识库文档索引时自动构建）。
